# Security policy

## Supported versions

JEM Migrator 0.1.x is a prototype for testing on a copy of a site, not a production-supported release. Security fixes are considered for the latest published 0.1.x package; earlier prototypes are not maintained. This policy does not change the support policy of JEM or of the source components.

## Scope

This repository contains the Migrator component, source adapters and the JEM import plugin. Reports about the import plugin are coordinated with the [JEM project](https://github.com/jemproject/JEM-Project). Vulnerabilities in third-party event components should also be reported to their maintainers.

## Reporting a vulnerability

Please report suspected vulnerabilities privately to **info@joomlaeventmanager.net**. Do not disclose an unpatched issue in a public GitHub issue or forum post.

Include the affected version and component, Joomla and PHP versions, the required permissions or configuration, reproducible steps, and the potential impact. Share only the minimum data needed to reproduce the problem; remove credentials and personal information from logs and sample databases.

The maintainers will assess the report, coordinate a fix and agree on public disclosure with the reporter. As this is a volunteer-run prototype, no response or release time is guaranteed. Good-faith reports are welcome.
